# Artikeldaten Import
Diese Python Scripts erstellen aus den Angebotslisten von Produzentinnen CSV Dateien für den Import in die Foodsoft. Dabei werden Bestellnummern erzeugt, die eine eindeutige Zuordnung und damit eine Synchronisation bei neuen Listenversionen ermöglichen (im Gegensatz zu: jedes Mal aller Artikel in der Foodsoft löschen und neu importieren).
